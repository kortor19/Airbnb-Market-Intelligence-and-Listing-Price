# Airbnb-Market-Intelligence-and-Listing-Price
Project title: Airbnb Market Intelligence, Listing Pricing and  Guest Experience Analytics Platform 

PROJECT BACKGROUND
The short-term rental industry has experienced significant growth, with online accommodation 
platforms allowing property owners and hosts to offer different types of accommodation to travellers. 

Airbnb provides a marketplace where users can explore accommodation options based on location, 
price, property type, room type and other listing characteristics.

OBJECTIVE
investigate how listing characteristics, room types, location, host attributes and review-related indicators vary across the selected Airbnb markets.

The goal is to use statistical analysis to discover patterns and relationships that can support better understanding of the accommodation marketplace.
